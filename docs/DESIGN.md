# Анакопиа — дизайн-документ

## Улучшенный промпт

Исходная просьба: «Создай полностью рабочий apk файл с мобильной игрой про осаду анакопийской крепости наподобие Марио. Только абхазские названия, имена и персонажи, ничего грузинского. Геймплей разнообразный, сюжет интересный, наполненный».

Уточнённая версия, по которой делалась игра:

> Создай полностью рабочую мобильную игру для Android: подписанный APK, работает офлайн, Android 7.0+. Жанр — 2D-платформер в духе классических «марио»-подобных игр, тема — оборона абхазской крепости Анакопиа от войска Марвана (около 737 г.).
>
> **Содержание.** Только абхазские имена, топонимы и мифологические образы (Аҧсны, Псырҵха, Аҟәа, Аҩы, Абнауаю, Шьашәы…), ничего грузинского. Исторический антагонист — Марван. Историю подавать уважительно, без карикатур. Вымышленных героев явно отделить от исторических фактов (экран «Об истории»).
>
> **Геймплей.** Минимум 8 глав, у каждой своя ведущая механика:
> - классический платформер: прыжок переменной высоты, удар по врагам сверху, тайники с дарами;
> - погоня с автопрокруткой;
> - оборона стен (касание — бросок камня);
> - пещера с ограниченным светом и прыжками от стен;
> - стелс (конусы обзора, укрытия);
> - скачка на коне;
> - вертикальный подъём;
> - финальный босс в 3 фазы.
>
> Два играбельных героя с разными способностями. Бонусы с местным колоритом. По 3 секрета в главе. Контрольные точки, жизни, сохранение прогресса.
>
> **Сюжет.** Рамка-сказительница, сцены с портретами до и после каждой главы, поворот в финале, бонусная концовка за все секреты. Немного юмора, но без глумления.
>
> **Техника.** Сенсорное управление (плавающий джойстик + кнопки), горизонтальная ориентация, полный экран, «Назад» = пауза, пауза при сворачивании. Звук и музыка синтезируются, графика — пиксель-арт, нарисованный кодом. Никаких внешних ресурсов, рекламы и сетевых запросов.
>
> **Качество.** Автотест проходимости каждой главы на реальной физике героя, сквозной тест сценария, проверка подписи и манифеста APK. Воспроизводимая сборка (Gradle + CI с запуском в эмуляторе), инструкция по установке.

## Механики по главам

См. таблицу в [README](../README.md#главы). Принципы:

- **Физика.** Фиксированный шаг 1/60 с. Прыжок до ~4,4 тайла вверх и ~5 тайлов в длину. Есть «время койота» и буфер нажатия прыжка. Опасные полосы не шире 3 тайлов.
- **Здоровье.** 3 сердца (мёд поднимает предел до 5). Удар отнимает бонус-огонь, если он есть, иначе сердце.
- **Противники.**
  - воин — патрулирует;
  - копейщик — с поднятым копьём на него нельзя прыгать;
  - лучник — стреляет навесом;
  - щитоносец — блокирует удары спереди;
  - всадник и кабан — бросаются в атаку;
  - летучая мышь, рыба, сталактит;
  - страж с факелом — конус обзора.
- **Боссы.**
  - Осадный мастер: прыжок → ударная волна → уязвимость.
  - Марван: конная атака в стену → оглушение; пеший бой со сменой атак; гроза, где молнию можно навести на самого Марвана.

## Технические решения

- **Рендер.** HTML5 Canvas с внутренним разрешением 240 px по высоте; ширина подстраивается под экран, масштабирование пиксельное. Статичные тайлы заранее отрисовываются в большой холст, динамические (вода, тайники, угли) — каждый кадр. Темнота в пещере — маска со «светом» вокруг героя и кристаллов.
- **Звук.** Web Audio: синтезированные эффекты и секвенсор с 13 мелодиями в ладу ре минор/дорийском с «бурдоном».
- **Android.** Полноэкранный `WebView` грузит игру из `assets`. Есть JS-мост для вибрации. «Назад» отдаётся игре. Схема подписи v2.
- **Сборка без SDK.** `tools/build_apk.py` сам кодирует бинарный `AndroidManifest.xml` и `resources.arsc`, компилирует Java в DEX через dalvik-dx и подписывает apksig. Проверено androguard и apksigtool.
